# Navicat UI/UX 对齐实施计划 — 2026-11-05

依据 [本轮审计](navicat-ui-ux-gap-audit-2026-11-05.md)，实施 UX15–29 的高频工作流改进。继续使用已有模块和三个引擎共享的数据文档；同步、自动运行、建模等独立产品能力另行评估。

## 实施顺序与验收

| 阶段 | 范围 | 实施内容 | 验收标准 |
| --- | --- | --- | --- |
| 1 | UX26、28 | 数据页保存菜单/Ctrl+S；统一表导出向导，整表 JSONL 显式独立入口 | 活动文档命令不串页；普通导出可选择格式/范围；不绕过忙碌、不确定提交和原会话检查 |
| 2 | UX15、16、20 | 扩展设计表格空间，折叠高级属性，结构化普通索引/约束编辑，明确子页选中态 | 六字段表无需额外滚动；PG/SQLite 普通索引可选列/顺序/唯一性；高级定义和 SQL 保存确认保留 |
| 3 | UX17–21 | 显式当前/选区/全部运行菜单；紧凑结果/消息页；可调整字段面板；有限额结果快照；查询结果多格式导出 | 执行范围可见；小窗口网格仍可阅读；固定结果重跑后保留原内容；导出明确缓存结果/选区及截断 |
| 4 | UX25、27、29 | 同一数据文档的记录表单、直接跳页、未提交草稿撤销/重做 | 表单与网格共享草稿与身份；分页校验和离开守卫保留；撤销不重放已提交写入 |
| 5 | UX22–24 | 按引擎组织分类/信息；条件启停与就地错误反馈；整理默认状态栏和视觉层级 | 不适用属性不冒充未知；筛选仍按引擎参数化；默认反馈突出行数/草稿/读写状态 |

## 实施约束

- 私有结果通道仍只在 UI 线程消费；运行、保存、分页与取消继续使用已有请求生命周期。
- 跨连接动作捕获原文档和会话身份；不自动执行恢复的 SQL，不重放不确定提交。
- 保留现有布局键与存储格式；新增状态使用兼容默认值。
- 修改中英文 JSON 翻译，再通过 MyGo 生成目录。
