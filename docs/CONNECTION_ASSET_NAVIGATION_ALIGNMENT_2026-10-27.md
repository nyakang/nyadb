## 技术决策

1. 保持 MyGo 原生 `ui.Outline`、`ui.Menu`、`ui.SearchField`，不复制 Navicat 资源。
2. 新增仅表示加载状态的内部 `navigationNode{Kind:"status"}`，不参与对象身份、持久化与表打开；仅失败节点显式重试。
3. 继续让对象服务只查询确实支持的表与视图。其他分类保持完整导航外观但不会声称元数据已实现。
4. 配置切换从数据库读取最新 Profile 后更新 `ActiveVariant`；禁止修改连接中／已连接档案，以免活动会话与 UI 配置不一致。凭据仍依照已有独立密钥库流程处理。
5. 维持连接树单选和右键全行命中，保留已有异步请求代际防护，未进行数据库 DDL 或驱动能力扩展。
6. 会话多开是跨服务层的独立里程碑：先按 ProfileID 维护 session slots，再隔离对象缓存、异步取消、工作区状态，最后做多连接真实 GUI 回归；不能只删除 `disconnectMySQLSession()`。
