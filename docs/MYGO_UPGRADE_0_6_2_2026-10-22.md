# MyGo v0.6.2 升级与 Fork 差异验证（2026-10-22）

## 版本与源码来源

- 上游正式发布：`egoist/mygo v0.6.2`，GitHub release 发布于 2026-10-21；tag commit `cf26587264f26ea68bd1b8abbf5c9723f35e0a70`。
- 原来 NyaDB 使用 `v0.6.0` 和 Fork 定制版 `v0.6.0-nyadb.1`；现升级至官方 **v0.6.2 基线** 的独立 Fork 定制版 `nyakang/mygo v0.6.2-nyadb.1`。
- Fork：<https://github.com/nyakang/mygo>；定制分支 `nyadb/v0.6.2`；固定标签 `v0.6.2-nyadb.1`，两者已推送至 GitHub。
- 原生表头补丁从旧 Fork commit `45a1d0a` cherry-pick 到 `v0.6.2` 基线，未产生冲突。与官方新版本比较，只有 `ui/table.go` 被修改（38 行新增、2 行删除），另有独立维护文档 `NYADB_PATCHES.md`；上游 `main` 未写入定制代码。
- 上游 `v0.6.0...v0.6.2` release 范围未改动 `ui/table.go`，因此原生 Table 的双行标题、类型标记和字段属性标记可直接迁移。

## NyaDB 依赖

```go
require github.com/egoist/mygo v0.6.2
replace github.com/egoist/mygo => github.com/nyakang/mygo v0.6.2-nyadb.1
```

`go mod tidy` 成功下载了 GitHub 版本；`go list -m github.com/egoist/mygo` 验证实际使用 Fork 的 `v0.6.2-nyadb.1`。Fork 继续保持官方 module path `github.com/egoist/mygo`，无需修改已有 import。主仓库原有已暂存的 Fork 迁移和其他未提交 UI 修改均保留，不擅自提交、推送或重置。

## 后续更新方法

优先在 Fork `main` 同步官方更新；有正式新版本时再以精确上游 tag 创建新的 `nyadb/vX.Y.Z` 分支、迁移最小补丁并运行完整验证；通过后发布不可变 `vX.Y.Z-nyadb.N` 标签，再升级 NyaDB 的固定依赖。官方若提供等价原生表头 API，应优先移除补丁。
