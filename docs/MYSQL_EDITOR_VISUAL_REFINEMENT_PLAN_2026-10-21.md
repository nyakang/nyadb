## 基线与范围

截至 2026-10-21，NyaDB 的 MySQL 连接编辑窗口已完成「常规 / 高级 / 数据库 / SSL / SSH / HTTP / 备注」七个主要标签，以及从高级页打开的「兼容性」子页的第一轮 Go/MyGo Native UI 独立实现（I）。这不是 Navicat 原版的功能等价声明；真实数据库连接、证书握手、SSH/HTTP 隧道和大量参数应用仍未接入驱动。

- 原版运行观察：隔离 Xvfb `:121`（或历史研究资料），研究记录见 `docs/MYSQL_*_DIFFERENTIAL_2026-10-21.md`。
- NyaDB 当前 GUI：隔离 Xvfb `:129`，窗口 900×700；备注页当前截图见 `temp/research/mysql-notes-20261021/`。
- 各截图必须标注原版 O、独立实现 I、实际差分验证 V 或 Unknown。研究图片只能保留在 `temp/research/`，不得复制 Navicat 素材进正式产品。

**2026-10-21 进度：** 完成第一轮公共 chrome（窗口背景、主标签边界、共享连接示意图、底栏按钮）的独立实现与七页 GUI 回归；已测量原版与 NyaDB 背景颜色并单独记录。见 `docs/MYSQL_CONNECTION_CHROME_DIFFERENTIAL_2026-10-21.md`。公共外观仍未达到像素级 V，接下来重点处理表单几何和新建/编辑布局差异。

## 视觉差分优先级

| 优先级 | 收敛区域 | 当前差异 / 操作 | 验收标准 |
|---|---|---|---|
| P0 | 固定截图基准 | Xvfb 窗口尺寸、Openbox 标题栏与主题/DPI 可能不同 | 统一 900×700 客户区、显示分辨率、缩放、主题、初始数据，按标签逐张采集同状态截图 |
| P0 | 标签页与表单几何 | 一些页曾出现 MyGo Row 高度不足、Select 箭头偏移、二级 Tabs 留空等问题 | 全七页逐行标注 x/y/w/h，浏览按钮与输入框垂直居中、无溢出或裁剪 |
| P0 | 新建/编辑流程 | 原版「编辑连接」出现连接配置文件侧栏；NyaDB 当前仍采用编辑窗口草稿 | 同时观察并归档新建、保存后编辑、返回、取消、重复打开的结构差异 |
| P1 | 连接示意图 | NyaDB 使用独立绘制图标，与原版造型、锁标记和连接线仍不同 | 校验各隧道状态下节点数量、连接线位置和可访问描述，不复制原版素材 |
| P1 | 字体和输入态 | Label、TextArea、Tab、Checkbox 等字体大小、边框、禁用色、焦点色存在差异 | 截图逐像素对照（记录容差），实测焦点、悬停、键盘 Tab 顺序与禁用态 |
| P1 | 高级/兼容性/数据库 | 宽度与字段密度、空表格、下拉尺寸、只读说明需再逐一比对 | 默认、切换、编辑和恢复状态各留 O/I 截图 |
| P1 | SSL/SSH/HTTP 子项 | 凭据保存选项因无安全密钥库而禁用；数据库驱动未应用这些设置 | 保持显式能力差异，列明哪些已实现配置、哪些尚未真实连接 |
| P2 | 备注页 | 已对齐主文本区域大小（约 860×475）、上方标签与下方提示，边角/聚焦色仍与原版不同 | 长文本滚动、换行、输入法、粘贴和高 DPI 渲染回归 |
| P2 | 跨平台 | 目前主要在 Xvfb 测试，Windows/macOS 未覆盖 | 在实际桌面设备验证窗口管理、输入法、文件选择器、缩放、凭据清理 |

## 统一复核流程

1. 从可核对的已授权 Navicat 运行观察获得默认与交互截图，记录环境、控件动作、尺寸；遇到需要真实服务器的功能先标 Unknown。
2. 使用当前 MyGo Native UI 复现相同状态，不引入 WebView/仿制素材；每次只解决一个显著差分区域。
3. `ui.NewTester` 验证控件联动、编辑与取消、配置生命周期和禁用状态；必要时使用隔离的本地测试数据库。
4. 执行 `go test ./...`、`go vet ./...`、`go tool mygo vet`、`go tool mygo build`。
5. 在真实 Linux Xvfb 桌面回归并比对 O/I 图，按发现记录 O/I/V/Unknown；不要把“编译通过”或“显示接近”直接升级为 V。
6. 每完成一个独立且已验证的差分步骤按用户约定进行 commit + push，不改写历史、不触及生产数据库。

## 当前结论

MySQL 新建连接各主要页的**首次 UI 实现已覆盖（I）**；未建立全窗口视觉 V 验收，更不等同于完整 MySQL 连接功能。优先从统一采图基线和新建/编辑两种窗口的几何结构开始，随后逐页解决显著控件差异。
