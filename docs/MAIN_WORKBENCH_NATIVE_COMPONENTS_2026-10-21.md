# NyaDB 主工作台 MyGo 原生组件改造计划（2026-10-21）

## 目标和边界

基线：MyGo v0.6.0；保留 NyaDB 的三栏布局、暗色主题、窗口大小、连接档案存储和数据库功能边界。仅更换工作台的交互容器，优先使用 SDK 原生控件，**不**复制 Navicat 私有资源，不触碰原版程序，不连接生产数据库。

## 设计决策

| 区域 | 改造 | 原因与约束 |
| --- | --- | --- |
| 顶部菜单 | `ui.ButtonBase().Menu` | 使用 MyGo 原生弹出菜单行为，同时保留菜单位于窗口标题栏之下的跨平台一致布局；不与操作系统全局菜单重复。未实施的命令明确显示待开发状态。 |
| 顶部大图标工具栏 | `ui.Toolbar` + 自定义图标按钮 | 用原生 Toolbar 键盘导航及窄窗口溢出菜单；保留上图下字视觉布局。 |
| 对象操作栏 | `ui.Toolbar` | 低宽度时溢出收纳，保持操作逻辑；不改数据库逻辑。 |
| 工作区页签 | `ui.TabsBase` | 自定义图标及逐页关闭、页签右键菜单，保留 MyGo 键盘选择行为；对象页签永久存在。 |
| 连接树 | 保留 `ui.Outline`，增加行级 `ContextMenu` | 展开与虚拟列表仍由 SDK 管理，提供与对象关联的上下文操作。 |
| 信息面板 | `ui.Collapsible` | 在有选中对象时展开/收起详情；保留未选择的空状态。 |
| 数据网格、编辑器、分栏 | 无需替换 | 已使用 `ui.Table`、`editor.View`、`ui.SplitPercent`。 |

## 验收

1. 菜单中的核心已实现命令可以操作连接、SQL 页签、显示/隐藏信息面板；未实现的命令不假装执行。
2. 1280×800 和窄窗口保持可操作，不依赖横向滚动找主要工具栏动作；键盘导航及溢出由 MyGo 提供。
3. 每个可关闭页签都能独立关闭，非活动页关闭不改变当前文档；`对象` 页签不可关闭。
4. 原连接树的选择、搜索、操作和确认逻辑不退化；上下文菜单只作用于对应项目。
5. 新增 `ui.NewTester` 回归验证；执行 `go test ./...`、`go vet ./...`、`go tool mygo vet`、`go tool mygo build`。
6. 上述测试属于编译/无窗口测试，不等同于真实桌面或 Navicat 差分验证。

## 里程碑

- P1：菜单 + 对象操作栏。
- P2：主工具栏及窄窗口处理。
- P3：可关闭页签及上下文菜单。
- P4：连接导航右键菜单、信息分组、测试和文档。

## 实施及验证结果（2026-10-21）

- P1 已完成：顶部菜单改为 MyGo 菜单弹出行为；对象操作栏改为 `ui.Toolbar`，刷新按钮固定在右侧。
- P2 已完成：主命令栏改用 `ui.Toolbar` 管理命令溢出；保留自定义图标/文字按钮及暗色细边框，“信息”按钮固定在右侧。
- P3 已完成：`ui.TabsBase` 显示对象/SQL/数据图标，支持逐页关闭、右键关闭及关闭其他页签；状态逻辑保证关闭非活动页不会切换当前文档。
- P4 已完成：连接档案及模拟连接树行级 `ContextMenu`，详情 `ui.Collapsible`，并新增对应 `ui.NewTester` 用例。
- 验证：`go test ./...`、`go vet ./...`、`go tool mygo vet`、`go tool mygo build` **通过**；构建产物为 `build/linux-amd64/`。更新 `docs/ui-preview.png`（1552×966 的 MyGo 无窗口渲染）。
- 未验证：Windows/macOS/Linux 实际 GUI 与 Navicat 原版的差分视觉验证。当前能控制的 Windows 桌面没有运行本次构建的 NyaDB；构建所在 Linux 主机没有图形桌面。无窗口渲染和编译成功不可替代真实 GUI 验证。
- 边界：菜单项中的低频未实现功能保持禁用，不宣称已完成数据库执行、导入导出。未提交、未推送。
