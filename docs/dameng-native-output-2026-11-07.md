# 达梦原生输出参数基础 — 2026-11-07

达梦 DPI 和每物理连接的私有 worker 现在支持 `ExecContext` 的 `sql.Out`。
这补齐了保存前置的实际主键返回路径，尚未开放共享网格保存或注册工作台。
当前正式连接产品仍为 16 个；达梦的 Saver、Verify、EditableTables、数据
事务工作区、导入导出及正式入口仍待实现和验证。

## 已验证的原生行为

固定自有 Docker 服务为 DM8 `08134283904-20220804-166351-20005`，原生模式
0、UTF-8、大小写敏感、LENGTH_IN_CHAR=1。Linux amd64 上三个已准入原厂
客户端分别为 `8.1.2.128/2022-08-04`、`8.1.3.59/2023-07-25` 和
`8.1.5.88/2026-09-22`；每个客户端均通过明文和验证服务器身份的 TLS 测试。
这不扩大此前的原生 ABI 或完整双向证书认证证明。

返回结果集的裸 `INSERT/UPDATE … RETURNING` 被固定服务器以 `-2007`
拒绝；原生匿名块中的 `RETURNING … INTO` 可执行，并可通过输出参数取得
数据库返回的主键和值。例如：

```go
var key int64
var savedText string
_, err := original.ExecContext(ctx,
    `BEGIN INSERT INTO "SYSDBA"."T"(V) VALUES(?)
       RETURNING ID,V INTO ?,?; END;`,
    text, sql.Out{Dest: &key}, sql.Out{Dest: &savedText})
```

以上示例要求表已经存在，且调用方继续检查原始语句和事务的实际结果。
真实测试证明：

- 主键 `9007199254740993`、int64 两端边界、38 位 DECIMAL 的文本返回
  均完整保留，独立原生查询与输出值一致。
- IDENTITY 实际键、DEFAULT 值、虚拟生成列和 BEFORE INSERT/UPDATE
  触发器修改后的文本均可返回；预编译 UPDATE 复用时结果归属于本次调用。
- `SQL%ROWCOUNT` 可独立返回本次 UPDATE 的行数。匿名块的普通
  `RowsAffected` 不被当作整个批次或每次写入的保证。
- NULL、空文本、8 KiB 文本及达到同一字节上限的多字节文本分别验证。
- 原始物理事务内的输出可用；提交与回滚后的独立查询分别证明实际行数。
  输出参数确认语句执行，不代表之后的 COMMIT 已获确认。

固定服务器拒绝 `INSERT … DEFAULT VALUES`（`-2030`），也拒绝对 IDENTITY
列显式使用本次探测中的 `VALUES(DEFAULT)`（`-2871`）；已验证的路径是在
可写普通列上使用 `VALUES(DEFAULT)` 并返回实际 IDENTITY。后续 Saver 必须
按原生对象元数据构造插入，不能照搬其它数据库的空行语法。

## 输出与取消边界

原厂 API 的 OUTPUT 方向为 `4`。接受的目的地址仅为非 nil 的 `*int64`、
`*sql.NullInt64`、`*string` 和 `*sql.NullString`；最多 128 个输出，每个文本
上限 8192 字节。输入输出双向参数、其它目的类型和 QueryContext 输出均在
执行前拒绝。LOB 完整值继续通过完整 RowReader 获取。

实测直接 BIGINT 输出绑定会把 `1.234` 静默变成 `1`。实现因此以原生文本
缓冲区接收整数，再做 int64 解析；小数、越界、非法文本、未写入或超限
指示器及原生成功附带警告均不会成为有效返回值。NULL 只允许可空目的类型。
超过文本上限的原生表达式被固定服务以 `-6108` 拒绝。

DPI 从已固定的缓冲区读取完整输出，先校验全部值，待外层原始操作的
网络/取消确认结束后一次性更新调用方变量。取消、原生错误或后续行数读取
失败不发布输出；执行之后无法证明完整输出时，关闭捕获的原始物理连接并
返回 `ErrOutcomeUnknown`，不返回可导致 database/sql 自动重放的 ErrBadConn。

私有 IPC 只传递目的类型描述符。子进程创建独立目的变量；成功后返回有序
输出值。父进程校验数量、类型、范围与全部值后才更新调用方变量。缺失、
额外、损坏或超限回执关闭原始 worker，保留结果不确定状态及变量原值。

真实取消测试验证预取消未提交、执行中取消等待原生确认并关闭原连接、
显式新连接可以恢复。真实故障代理丢弃已经执行的 INSERT 回执：目的变量
保持原值，原连接不可复用，独立查询证明只插入一次。小数、越界及 NULL
返回校验失败的测试也独立证明：写入可能已经成功，必须保留不确定结果。
注入测试另外覆盖外层取消、第二个输出损坏、原生警告及损坏 IPC 回执，
证明不会部分更新变量或关闭另一个原始会话。
