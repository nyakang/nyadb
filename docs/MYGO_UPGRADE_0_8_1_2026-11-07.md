## 定制补丁与兼容性

完整保留多行表头、COMMENT 提示、离散选列、独立表头操作菜单、单元格点击回调、条纹／网格、导航树三角／整行选中／右键菜单和 Windows 紧凑菜单。

移植过程中保留上游 `HeaderCell`、`CellsStyle`、自定义树 `Prefix`、无名称修饰键事件和取消按压语义。`CellsStyle` 显式配置的行／条纹颜色优先于 `TableStyle` 的后备条纹；离散选列的绘制与选中判定一致。取消的按压不触发单元格编辑回调。

Windows 默认尺寸与 v0.8.1 一致；紧凑模式接入新测量／绘制路径，保留独立快捷键字体、图标列、DPI 宽度补偿、字体失效、Acrylic 和纯色回退。Windows 确定性测试新增默认尺寸不变检查，延续两种密度、菜单／DPI 隔离和宽度补偿检查。

新版测试器对点击目标更严格。Fork 的重复标签查找逐个核对实际输入目标，选择可达控件；全部被遮挡时仍失败且不发出点击。回归覆盖重复标签和遮挡拒绝。

NyaDB 数据工作区以 `ObserveInput` 观察按压，替代覆盖单元格文字的输入处理层，保留选择前结算编辑、取消后清除按压状态及原生右键菜单。新增取消按压后无编辑／草稿／写入、随后正常点击恢复的回归。openGauss 注释测试在启用注释后滚动到新增输入框，再执行真实可见输入。

完整可重建补丁：[mygo-v0.8.1-nyadb.1.patch](patches/mygo-v0.8.1-nyadb.1.patch)。独立上游基线重建的 25 个变更文件与发布树逐字节一致。旧补丁和旧版本研究脚本保留原版本含义。
