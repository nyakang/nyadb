# 表数据整格编辑与单击修复（2026-10-29）

## 行为与实现

普通文本及 JSON 单击后，原生输入控件覆盖整个单元格，包括表格留白；四边显示直角蓝色边框。用单行测量占位保留行高，原生右侧和底部网格线仍占最外侧一像素。输入中的文本选择和右键操作沿用 MyGo。

预览使用整格点击区域，以实际边界判定相邻行列。输入回调通过绑定的 MyGo Handle 读取当前显示帧坐标，覆盖首次显示、窗口缩放、列重排和滚动。只有配对的无修饰主键按下／释放且未拖动才进入编辑。

进入编辑保留当前列表位置，完整值读取完成后同样不提交滚动请求。Tab／Shift+Tab 和 F2 仅在目标行位于视口外时请求滚动；新增行继续滚到新记录。网格使用固定控件身份，读取／错误状态行的显示不会重建原生滚动容器。100 行分页回归覆盖已滚动视口内的普通／长字段点击、取消、读取后的水平位置，以及键盘跨出视口后显示目标行。

截断长文本及 JSON 先调用完整行读取，再按请求进入整格编辑；二进制字段自动打开十六进制专用编辑器。完整字段草稿直接复用，新增二进制记录也保留字节语义。读取请求携带行身份、字段名和编辑模式，消费结果时校验请求、连接代次、身份及快照。失败、超限、缺字段或冲突不产生编辑草稿。

继续使用 Go 1.27.3 和 MyGo v0.6.4-nyadb.4。公共服务接口和本地数据库结构未调整；完整读取与编辑限制、生成列／无唯一身份限制、默认跨行提交和批量模式沿用现有实现。
