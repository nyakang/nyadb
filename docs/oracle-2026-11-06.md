# Oracle 接入（2026-11-06）

Oracle 接入现有连接选择器、配置存储、会话运行时、导航、SQL 工作区及共享数据工作区。采用固定版本 `github.com/sijms/go-ora/v2 v2.9.0`，无需 Oracle Instant Client，应用保持 `CGO_ENABLED=0` 构建。

## 连接与 SQL

- 常规页配置主机、端口、服务名或 SID、用户名及独立凭据；默认端口 1521，默认服务名 XEPDB1。PDB 使用服务名；SID 通常连接实例所在的根容器。
- 高级页配置默认 schema、应用名称、拨号超时及独立的后台/SQL 连接上限（各 1–64，默认 8）。公开配置保存在现有引擎选项 envelope，不新增数据库迁移，也不把密码存入 profile。
- TLS 提供 disable、require、verify-full。verify-full 支持 CA 文件和证书服务器名，检查证书链及身份；require 只加密。TCPS 需使用服务端实际监听端口。当前不支持 TNS 别名、钱包、外部认证、SSH/HTTP 隧道或客户端证书。
- URI 示例：`oracle://user:password@host:1521/XEPDB1?connection_type=service&schema=APP`。解析结果的密码保持临时秘密，错误不回显原始 URI；未实现参数明确拒绝。
- SQL 租约固定物理连接，保留事务及成功设置的 CURRENT_SCHEMA。词法处理支持 Oracle q/nq 字符串、匿名块和程序定义；批次中 PL/SQL 块使用单独一行 `/` 分隔，分隔符不发送给服务端。
- 普通 Oracle SQL 错误不丢弃租约。取消关闭原始物理连接并等待操作回执，旧租约要求显式恢复；不会自动重放 SQL。后台读写与 SQL 使用独立池。
- EXPLAIN PLAN 使用随机 statement ID，在原 SQL 租约读取 PLAN_TABLE 的树形节点并清理自己的计划行。服务端权限或 PLAN_TABLE 不可用时明确失败。

## 对象与共享数据

- Namespace 身份是 ProfileID/Catalog/Schema，catalog 来自 Oracle 返回的容器身份。schema 和引号内对象名保持大小写，不把服务名当成 schema 或导航标签。
- 浏览表、视图、函数、过程、程序包、触发器、序列及类型；程序定义读取 ALL_SOURCE，程序包同时保留 body。表/视图及可访问的自有序列 DDL 使用 DBMS_METADATA；外部 schema 的目录浏览不会因为缺少 GET_DDL 权限而全部失败。
- 表结构包括列、精度、NULL/default、identity/virtual、索引和外键。程序工作区保留完整定义，最多展示 500 行。
- 使用唯一的 dataworkspace State/Document 与共享表格。支持 OFFSET/FETCH 分页、组合过滤、排序、计数、类型化剪贴板/导出、字段查看、数据分析，以及插入/更新/删除和显式事务。
- NUMBER/FLOAT 使用十进制文本及驱动 Number 绑定，拒绝超过目标精度/scale 或 Oracle NUMBER 范围的值；DATE/TIMESTAMP 编辑也拒绝静默丢失小数秒。
- RAW/BLOB 保留字节；CLOB/NCLOB 保留文本。服务器端预览最多 1024 字符单元/字节，完整行编辑限制 1 MiB；导出按字段和行预算在服务器端检查，超限明确失败。
- 可编辑行要求完整、非空且可比较的唯一键。视图和包含不支持类型的表只读；LONG、LONG RAW、对象类型、空间类型等数据读取明确拒绝，不假装可安全编辑。
- 普通列快照使用 STANDARD_HASH；LOB 编辑要求可执行 DBMS_CRYPTO。没有该权限仍可预览、字段读取及导出 LOB，含 LOB 的表保持只读。是否授予 `GRANT EXECUTE ON DBMS_CRYPTO TO <user>` 由数据库管理员决定。
- 写入先在原事务中核对并锁定原行，再按完整 values/fingerprints 快照执行 DML。通过 RETURNING ROWID 读取实际生成键与触发器/default 后的值，不根据用户输入猜测已保存记录。
- 批次提交或回滚无法确认时保留不确定状态和草稿，禁止自动重放。导入复用共享向导，首版支持向已有可编辑表追加，同一事务提交；新表、多种匹配模式及遇错继续明确不可用。
- 暂不提供表设计器、对象修改/复制对话框、账户管理、维护、备份恢复；对应产品能力未声明，界面不会开放未实现的操作。

## 复现验证

真实服务器 fixture 使用独立 loopback 容器及临时密码；验收脚本只清理自己创建的容器，移除私有凭据，保留日志、截图和机器可读结果。

```sh
python3 tools/verify_oracle_fixture.py --output build/oracle-fixture
python3 tools/verify_oracle_fixture.py --race --output build/oracle-fixture-race
```

默认镜像 `gvenzl/oracle-xe:21-slim-faststart`。真实服务器测试通过 `NYADB_ORACLE_IT=1` 显式开启，必须提供隔离的 loopback 端口和 fixture 密码。脚本依次检查适配器、dbruntime 公共会话、shell 共享表格及可选 DBMS_CRYPTO 权限下的 LOB 编辑。shell 截图由 MyGo headless tester 的真实工作区绘制生成。

版本验证范围是 Oracle XE 21c。TCPS 证书链及服务器名有独立边界测试；当前真实 fixture 使用 TCP，不把它描述为真实 TCPS 服务验收。其他 Oracle 版本、字符集及外部认证方式尚未完成矩阵验证。
