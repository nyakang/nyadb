# NyaDB 连接导航右键菜单与底部工具栏（2026-10-22）

## 对比依据与目标

用户截图中的 ①（NyaDB）与 ②（Navicat 18）表明：原版标题栏仅显示“我的连接”入口，用户要求右侧设置图标通过悬浮出现；底部搜索右侧为筛选、星标、定位活动标签、全部折叠；针对空白、虚拟组、连接节点提供不同的上下文菜单。

**证据等级**：上述可见控件和位置属于 O（用户提供的截图观察）；原版三类右键菜单的完整命令集及菜单外观未由该截图证实，以下菜单内容为 NyaDB 独立设计（I），不得称为 Navicat 的精确行为复刻。未运行原版软件。

## UI / 交互实现

1. **标题**：删除常驻“新建连接组”和“添加连接”。标题栏 hover 后显示 15 DIP 的设置图标，调用 MyGo 原生菜单；标题栏右键也可打开同样菜单，支持键盘上下文菜单入口。
2. **空白菜单**：在 Outline 空白区域及其外层容器使用 MyGo 原生 ContextMenu，提供新建连接、新建连接组、展开组、全部折叠、刷新。空白右键不会误使用之前选中的连接。
3. **虚拟组菜单**：组内新建连接、创建新组、展开/折叠该组、重命名、删除连接组、刷新。删除组依然采用原有确认和解除归组的事务语义，不会删除连接及数据库。
4. **连接档案菜单**：MySQL 连接/断开（根据实际会话状态启用）、编辑、复制、添加/取消星标、移动到组、删除、刷新。连接相关操作基于右键命中的具体档案，不错误作用到当前其他选中项。非 MySQL 类型未接入的会话功能保持禁用。
5. **固定底栏**：搜索框 + 筛选（MySQL/PostgreSQL/SQLite/全部）+ 仅显示星标 + 导航至活动标签对象 + 全部折叠，使用 MyGo 原生按钮和嵌入式 Lucide。激活星标筛选后，仅显示本地已收藏档案及包含其成员的组；对空组不伪造收藏数量。
6. **定位**：仅对当前真实 MySQL 数据或结构标签存在有效会话时可用。临时移除筛选和搜索以显示目标连接，展开所在组和数据库树，依据真实元数据在加载后选择对应对象行；无对应会话不连接数据库也不跳转。
7. **连接会话操作**：密码与连接/断开不再挤占左下固定工具栏；仍仅在当前会话中保留密码输入，现改置于选中连接的信息面板。
8. **星标持久化**：本地配置数据库 schema 6→7 新增 `connection_profiles.starred`，默认 false，不传送到 MySQL、不存储机密。使用独立 `SetStarred` 服务 API 直接更新星标字段，避免修改旧连接参数的竞争和凭证影响。
9. **菜单资源**：增添 pinned Lucide v0.468.0 中 ISC 授权的 `settings-2`、`star`、`locate-fixed`、`chevrons-up`，沿用已有许可及 Go embed，不引入第三方 WebView。

## 验收范围

- UI：MyGo `ui.NewTester` 无窗口交互检验空白/组/连接三类菜单独立性、悬浮设置菜单、星标筛选、类型筛选、折叠和活动标签匹配。
- 服务：星标的持久保存、清除和非法 ID 拒绝；数据库升级测试验证旧组与连接档案不丢失。
