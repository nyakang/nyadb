## 续作审计与实现接线（进行中）

- 生产入口改为导入六步骤、导出五步骤，800×620 DIP 基准，主体滚动与固定底部按钮。输入读取/准备/写入都使用私有缓冲结果通道；UI 消费停放结果。
- 源与映射暂存分别存为私有 JSONL，完整解析后仅保留最多 100 行预览。每次打开读取器验证 SHA256，读至 EOF 再验证本次读取指纹；中途修改也会使整次写入回滚。
- 源解析设置和目标身份加入确认指纹。源设置修改必须重新读取；目标表切换清除原映射、匹配键、确认和校验状态，禁止借用当前表元数据。
- TXT/CSV/TSV 的流式读取支持单字符分隔/识别符、无识别符、字段名行或自动字段名、行范围及可选编码。导出对应设置已接入；不可表示的字符/字段直接失败，原文件保留。
- 多来源各自持有目标/映射/设置/准备文件；写入按目标顺序、每个目标一次事务。确认页明示后续失败不会回滚先前完成目标。逐目标回执与完整磁盘逐行日志核对；计数矛盾或日志缺失不能宣告成功。
- 命名配置为版本 1 JSON，最多 20 项/256 KiB，名称和参数有界，提供保存/加载/删除，外部源连接字符串与密码不持久化。
- ODBC/Access/Paradox 中立服务 API 及 bootstrap 注入已接入。缺失本机组件时检测详情和组件路径设置保留；正常编译不链接这些组件。

这些属于正在回归的代码，尚不是最终 I 或 V 验收。当前 UI 编译仍等待 DBF reader 完成；JSON/XML/HTML/XLSX 的大文件流式解析、服务批量插入、真实本机读取和实际窗口仍由对应子任务继续完成。
