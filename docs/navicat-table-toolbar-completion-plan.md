## 实现与归属

- `dataworkspace` 持有步骤、解析/映射、配置、临时文件、逐目标结果及文档生命周期；源、映射与确认指纹绑定原 profile/generation/目标。工作线程捕获深复制请求，私有缓冲通道只在 UI 消费。
- 源与映射存为私有 JSONL；预览最多 100 行，完整读取后才能确认。每次打开及 EOF 验证 SHA-256，中途修改、日志写入失败会使目标事务回滚。
- MySQL 流式导入每目标一个物理连接和一次事务；10000 行/16 MiB 是批次上限。取消等待执行器与回滚回执；不确定提交禁止重放。后续目标失败不回滚已提交目标，确认页与逐目标回执必须一致。
- `datasources.Source` 和 `ImportMySQLDataStream` 保持既有接口；bootstrap 注入本机来源。组件仅按需检测，正常构建不链接 ODBC/MDBTools/libpx；配置不保存外部连接字符串或密码。
- 不自动提交/推送、不修改故障旧会话数据库。截图与日志放忽略目录，O/I/V 必须与实际请求、文件或 SQL 结果绑定。
