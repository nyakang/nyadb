# 达梦原生共享数据事务 — 2026-11-07

达梦私有 Session 实现完整 `contract.DataTransactions`：Begin、Page、
Save、Row、Chunk、Commit、Rollback 和 Close。事务中的分页、完整字段和
暂存修改共享原始物理连接，复用已有读取与精确保存实现。正式工作台
provider/chooser/editor 尚未注册，连接产品仍为 16，导入导出继续待完成。

## 原始连接与保存点

每个令牌绑定原始 Session 和 Profile/Catalog/Schema/表身份。Begin 在
读取结构前设置 SERIALIZABLE 并持有 EXCLUSIVE 表锁，直到提交、回滚或
关闭。事务仅开放已验证可编辑的普通表；含 LOB 且带任何触发器的表仍
被拒绝，包括停用触发器。原生 locator 回滚缺陷见
[精确保存报告](dameng-native-data-edit-2026-11-07.md)。

数据事务使用独立有界物理池，容量取现有 MaxConnections，不改变配置
格式。元数据和 SQL 文档保留各自的池。池满时等待当前请求的取消或释放，
不会增加无界连接。初始保守的 EXCLUSIVE 策略也会阻塞目标表上的其它
写入及需要相应锁的读取；它不具备行级并发编辑语义。

Begin 请求的取消范围在发布前安全解除。令牌的生命周期绑定原 Session，
而每次提交、回滚和读取使用当前请求的上下文。原生 DPI 和私有工作进程
支持 CommitContext/RollbackContext；短原子操作仍使用原有 driver.Tx。
测试取消 Begin 上下文后，原始事务仍可读取、保存和提交。

真实服务器接受 SAVEPOINT、ROLLBACK TO SAVEPOINT 和固定名称的替换，
但 RELEASE SAVEPOINT 返回 -2007。每次 Save 复用 NYADB_DATA_BATCH，
全批校验、执行和最终行重读均在该保存点内。后续 UNIQUE 失败恢复这一
批次的标量/CLOB/BLOB 替换，此前成功批次继续暂存并可读取，不隐式提交。

每次成功 Save 和 COMMIT 前都重读净暂存行。跨批次修改保留最初完整值
及最终实际键；插入后修改保留插入身份，插入后删除没有净行变更。令牌
证据与调用方结果持有独立副本。完整字段和 1024 单位预览复用既有读取
界限；累计成功语句最多 1000，完整暂存证据也受 64 MiB 预算限制。

## 取消、回执与关闭

取消和关闭先撤销请求，再等原始执行确认及原始回滚确认。令牌、会话
关闭和并发 Close 均不会提前发布完成，不会寻找新连接重放 SQL。提交
成功后销毁该物理工作进程，避免复用原生会话或事务属性。

工作进程区分发送前的取消和已发送的终止请求。发送前取消保留原始
回滚句柄；已发送 COMMIT 的失败确认返回不确定结果并永久停用令牌。
原生提交成功但 driver 回执被丢弃时，CommitError 保存完整净变化、实际
生成键和触发器最终值，不设置 CommitConfirmed，不重发写入。提交前
重读失去原连接时保留已有证据并标记 Incomplete，供共享工作区保留草稿。

VALID 的 DBMS_LOCK.SLEEP 触发器验证真实执行期间的取消。客户端收到
原始取消确认后，服务器睡眠可能继续暂时持锁；测试只轮询有界的独立
只读查询，最终观察原值。产品继续保留不确定状态，不以服务器最终
原值补造提交回执，也不重试 UPDATE。
