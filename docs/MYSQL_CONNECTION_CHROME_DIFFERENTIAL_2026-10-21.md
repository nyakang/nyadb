- **V：** 本轮仅验证“七个标签均保留公共区域、控件不越界、隧道状态跨页保留”等限定行为。**未通过全窗口逐像素 V**。

## 公共区域实测

| 区域 | 原版 O | 先前 NyaDB I | 当前修改 |
|---|---|---|---|
| 内容客户区 | 约 900×700（标题栏不计） | 900×700 | 保留尺寸，不通过移动 OS 窗口伪造布局 |
| 主内容背景 | RGB(49,54,59) | RGB(51,51,51) | 单独使用 `#31363b`，实际桌面像素采样与 O 相符 |
| 主标签栏 | RGB(48,53,58) 蓝灰 | RGB(40,40,40) 深灰 | 使用 `#30353a`，不更改主工作台的配色 |
| Tab/内容分界 | 约 29 DIP 高标签栏 | 29 DIP | 保留 MyGo `TabsBase`；采用接近原版的边界色 |
| 默认连接示意 | 双节点、连线约 113 px | 双节点位置偏远、线色偏暗 | 两端节点收紧；112 DIP 中灰色 `#76787a` 连接线 |
| SSH/HTTP 示意 | 三节点等间隔 | 节点间距较大 | 三个 65 DIP 节点列、75 DIP 连线，居中布局 |
| 底栏 | 左侧还有配置文件列表图标按钮；可见 URI、测试连接、右侧三按钮 | 缺少首按钮；左侧控件总宽较小且默认偏高 | 加入明确禁用的配置文件列表占位按钮，标准化按钮高度 26 DIP 和控件间距 |
| 标题栏 | 随原版 Qt/WM 变化 | MyGo OS 原生装饰 | 保持原生窗口，不仿造 Qt 标题栏，也不把系统装饰偏移计入 UI 差异 |

注：原版在截图中的客户端左上角常为屏幕 `(350,140)`，NyaDB 常为 `(350,135)`，属于两个独立窗口的 OS 装饰/摆放偏移；像素采样对比应先对齐客户区，而非直接比较全屏绝对坐标。灰色采样仅反映所测位置，不代表整体像素级一致。

## 独立实现（I）与回归

- 改动限定在 `internal/ui/shell/connection_editor_view.go` 的公共主窗口背景、TabsBase 视觉样式、连接示意图和 footer；不重写连接设置模型或具体标签页表单。
- 不使用原版图标或私有资源。连接示意仍用 NyaDB 自绘图标；原版连接图形、节点尺寸、字体位置和隧道小锁等尚有差异。
- 在页脚展示的配置文件列表按钮当前显式 **禁用**，因为原版“编辑连接”左侧配置文件面板尚未实现；不把它冒充为可用操作。URI 和测试连接同样仍受现有能力限制。
- 新增 `ui.NewTester` 回归用例，跨七页检查 URI、测试连接、上一步、确定、取消及连接图节点，并验证开启 HTTP 后跨页切换仍显示 HTTP 服务器节点。
- 真实 GUI 使用隔离运行环境依次采集七个标签页，同一窗口尺寸确认公共 chrome 未消失、布局未越界。构建与测试门禁包含 `go test ./...`、`go vet ./...`、`go tool mygo vet`、`go tool mygo build`。

## 尚待收敛（非 V）

1. 原版 Qt 标题栏与 MyGo 原生窗口的系统装饰不同，优先保留本机原生窗口，只比较内容客户区。
2. 主标签文字字重、宽度、键盘焦点、悬停/选中/禁用态需要更严格的交互与颜色差分。
3. 主示意图仍为独立绘制的 NyaDB 符号，不追求复制原版私有品牌造型；隧道状态下的锁标记尚未覆盖。
4. 原版“编辑连接”可能具有连接配置文件侧栏；目前按钮禁用、侧栏未实现。
5. MySQL 驱动、连接测试、URI 处理和全部参数实际应用未实现，属于功能差异，不能从 UI 显示效果推断已经可用。
