# MongoDB support

MongoDB uses the official pure Go driver v2.9.3 and the existing runtime manager,
session browser, query workspace and shared data grid.

## Connections and queries

Profiles support ordinary hosts, additional `host:port` seeds, replica-set names,
direct connections, SRV addresses, SCRAM authentication, authentication databases,
TLS certificate verification and a custom CA file. Passwords remain in the
credential vault or temporary session draft. URI imports accept `mongodb://` and
`mongodb+srv://`; unsupported options are rejected. SRV requires TLS.

The MongoDB query editor accepts **one native command in Extended JSON**. It uses
JSON highlighting and formatting. For example:

```json
{"find":"records","filter":{"active":true},"sort":{"_id":1},"batchSize":100}
```

`find`, `aggregate`, `listCollections` and `listIndexes` consume their server
cursors. Other commands display their complete response as a document preview.
Query results are limited to 1,000 documents, with previews limited to 1,024
characters. Use a native `explain` command for plans. SQL, mongosh JavaScript,
multiple commands, injected database/session identities and explicit
unacknowledged writes are rejected. Driver read/write retries are disabled.

## Collections and document editing

Navigation distinguishes collections and views. Collection metadata retains
the native collection options, validators and index definitions. The grid has
two presentation columns: immutable `_id` and a complete `document` in canonical
Extended JSON. These columns describe the grid projection; NyaDB does not infer
a relational schema from a document sample.

Canonical Extended JSON preserves ObjectId, BSON integer widths, Decimal128,
dates, binary subtypes, nested objects and arrays. Missing fields remain distinct
from explicit nulls. Full document editing is limited to 1 MiB of Extended JSON;
larger documents retain bounded previews and explicit field reads. Views and
system collections are read-only in the grid.

Each insert, replacement or deletion is acknowledged individually. Replacements
and deletions compare the complete original BSON document in the same atomic
server operation. A concurrent change produces a conflict. Original snapshots
carry session-bound authentication and fingerprints; reconnecting invalidates
captured operations. The driver does not replay writes. A partially completed
batch or uncertain acknowledgement retains drafts and prohibits automatic replay.
Verification distinguishes applied, unapplied and indeterminate outcomes.

Grid paging uses offsets and `_id` ordering. Grid filters support `_id` equality
and inequality, with values such as `{"_id":{"$oid":"507f1f77bcf86cd799439011"}}`.
Use native `find`/`aggregate` commands for other filters and sorts. JSONL export
streams complete canonical documents; tabular exports retain Extended JSON
strings. SQL copy/export is unavailable.

Transactions, import wizards, collection/index designers, administration,
backup/restore and SSH/HTTP tunnels are not implemented. Replica-set connections
do not enable transaction controls. Collection creation and index operations can
be performed deliberately through native commands.

## Verification

Run the isolated fixture verifier:

```bash
python3 tools/verify_mongodb_fixture.py
python3 tools/verify_mongodb_fixture.py --race --output build/mongodb/race-fixtures
```

It creates uniquely named loopback-only containers, keeps temporary authentication
secrets out of command arguments, and removes its own containers and private
files. It tests an authenticated standalone server and a single-node replica set.
The default fixture is the official `mongo:7.0.28` image. This host uses Linux
7.0; the downloaded MongoDB 8.0 image refuses to start because of the upstream
[kernel/allocator incompatibility](https://jira.mongodb.org/browse/SERVER-121912).
`--image` selects another official fixture version on a compatible host. MongoDB
8.x, Atlas/SRV networks and external TLS endpoints were not live-tested here.

Live tests cover BSON round trips, collection/index metadata, document editing,
stale conflicts, ordered partial batches, generated ObjectIds, bounded previews,
JSONL export, cursor continuation, cancellation, views without `_id`, public
generations, captured-operation revocation and the complete headless UI workflow.
Generated screenshots are in `build/mongodb/standalone/` and
`build/mongodb/replica/`; these are headless UI captures, not native-window captures.

Repository checks include full Go tests, affected-package race tests, Go vet,
MyGo vet, catalog validation, Python utility tests and Linux/Windows/macOS builds
with `CGO_ENABLED=0`.
