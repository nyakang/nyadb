# NyaDB UI-1 / UI-2 — Native workbench layout

Implementation date: 2026-10-20. Initial base: MyGo v0.5.5; current implementation uses v0.6.0.

For the 2026-10-21 native-component follow-up and verification, see
[MAIN_WORKBENCH_NATIVE_COMPONENTS_2026-10-21.md](MAIN_WORKBENCH_NATIVE_COMPONENTS_2026-10-21.md).

Reference: a user-supplied Navicat Premium screenshot. The layout and
interaction patterns are used as inspiration; NyaDB uses its own name, icons
and colors. No Navicat assets are included.

## UI-1: layout

- Top: compact MyGo popup menu row and colored icon command toolbar with native overflow handling.
- Main: a connection explorer with search, resizable central workspace, and
  optional right information panel, all backed by `ui.SplitPercent`.
- Center: permanent Objects tab, context commands and object table; SQL editor
  and data preview open in additional tabs.
- Bottom: a fixed status bar, with explicit "UI Preview" label.
- Theme: compact dark neutrals, blue selection, self-authored SVG icons.
- Resizing defaults: sidebar 22% of window; center 75% of remaining width;
  user can drag both splitters.

The native operating system retains ownership of the physical titlebar,
window buttons and normal focus/IME behavior.

## UI-2: implemented mock interactions

| Interaction | Outcome |
|---|---|
| Click a connection in the left tree | Selects a mock connection; renders object rows; updates inspector/status |
| Expand a connection node | Displays mock schema/table children |
| Type in connection search | Filters the connection roots (including Chinese text) |
| Toolbar: 新建查询 | Opens a new independently editable SQL tab |
| Toolbar: 表/视图/函数 | Switches Object tab and filters mock object types |
| Open selected table / double-click table row | Opens a virtualized synthetic Data Preview tab |
| SQL tab: 运行模拟查询 | Increments a demo counter and updates status; never runs SQL |
| Close current tab | Closes non-permanent tabs; Objects tab cannot close |
| Toolbar: 信息 / info panel close | Hides or restores the inspector |
| Resize splitters | Changes sidebar/inspector widths |
| Other toolbar/menu placeholders | Displays explicit not-yet-implemented status |

Data Preview contains **100,000 virtual rows and 50 virtual columns**, whose
cell text is constructed on demand. This is not a database query or
server-side pagination benchmark.

## Code ownership

- `internal/ui/theme/`: compact dark palette, original SVG symbols and shared
  connection/provider bitmap caches decoded once per process.
- `internal/ui/connectioncatalog/`: connection type catalog, chooser state,
  search, filters, grid/tree views, in-session recents and opt-in research icons.
  The chooser reports a `Choice` through a callback; shell owns window chrome,
  chooser footer actions, chooser errors and the transition to connection editing.
- `internal/ui/connectioneditor/`: raw editing drafts, native connection forms,
  alternate configurations, transient secrets, credential rollback and async
  connection tests. Services and host callbacks are injected; the editor owns
  no SQLite driver, MySQL transport or workbench session. `OpenNew`/`OpenProfile`
  initialize a session; `Close` invalidates pending checks and native picker
  versions and clears temporary secrets. `Saved`, `Back` and `Cancel` callbacks
  coordinate the editor with shell after secret cleanup.
- `internal/ui/navigation/`: qualified tree identities, profile/group snapshots,
  selection, disclosure, search/engine/star filters, prior-filter restoration,
  inline group editing and branded navigation icons. Read-only session metadata
  and explicit workbench actions are injected. The package imports no shell,
  storage or MySQL runtime service. `SetProfiles` reconciles selection after
  refresh and rename; `SuspendFilter`/`RestoreFilter` support active-tab reveals.
- `internal/ui/shell/profile_view.go`: navigator callbacks, document shortcuts
  and contextual profile inspector. Session activation, metadata jobs and object
  actions remain in shell; the existing profile navigation files coordinate
  those actions and build menus. Database opened state belongs to each session,
  independently of disclosure: single click selects, while double click, Enter
  or an explicit action opens and loads it. Failed reads require explicit retry.
- `internal/ui/shell/model.go`: workbench state, tabs, mock objects and
  synthetic result cell generator.
- `internal/ui/shell/chrome.go`: top chrome, command toolbar and statusbar.
- `internal/ui/shell/explorer.go`: mock connection explorer and search.
- `internal/ui/shell/workspace.go`: object table, SQL editor, virtual result.
- `internal/ui/shell/inspector.go`: contextual right panel.
- `internal/ui/shell/shell_test.go`: headless interaction regression tests.
- `internal/ui/shell/preview_test.go`: opt-in screenshot generator.

Chooser state and rendering tests live beside `connectioncatalog`; window and
connection workflow integration tests remain in shell. Editor form, configuration,
credential rollback and async-check tests live beside `connectioneditor`; shell
retains saved-password session and native picker forwarding regressions.
Navigator node, category, filter, inline-edit, virtualization and icon tests live
beside `navigation`; shell retains database-open, right-click target, active-tab
reveal, multi-profile session and late-result regressions, including 1280×800 and
840×560 layouts. Shared bitmap cache tests live beside theme. Resetting the chooser clears selection, search and
filters while preserving the current view mode, expansion state and recents.

After the navigator extraction, shell contains 120 Go files (48 implementation
and 72 test files), down from 127 (53 implementation and 74 test files) after the
connection editor extraction. Its 18 navigator fields are replaced by one module
instance. Navigation has six implementation and five test files; mixed tests
retain their workbench assertions in shell. Session workspaces and SQL, structure
and data pages remain available for subsequent extraction stages.

## Limitations / next steps

- Connection profiles, database credentials, SQL execution, metadata requests,
  and result paging are **not yet implemented**.
- Object toolbar actions such as import/export and structure editing are
  intentionally status-only placeholders.
- Menu row uses MyGo's native popup-menu interactions inside the content area,
  rather than platform-dependent OS menubar placement; unavailable commands are disabled.
- Layout sizes are retained only in memory for this run; persistence is M1.
- Physical OS GUI testing is still required on Windows, Linux and macOS:
  check titlebar, IME, DPI scaling, pane drag, keyboard navigation, tooltip
  overlay and horizontal grid scrolling.
