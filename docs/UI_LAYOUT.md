# NyaDB UI-1 / UI-2 — Native workbench layout

Implementation date: 2026-10-20. Base: MyGo v0.5.5.

Reference: a user-supplied Navicat Premium screenshot. The layout and
interaction patterns are used as inspiration; NyaDB uses its own name, icons
and colors. No Navicat assets are included.

## Rendered preview

![NyaDB UI preview, generated by MyGo headless tester](ui-preview.png)

This is a **real MyGo headless-rendered frame**, not a screenshot of a running
Windows/Linux/macOS GUI. It deliberately shows mock data and an empty objects
area until a demo connection is selected.

Regenerate after updating the UI:

```bash
NYADB_WRITE_PREVIEW=1 go test ./internal/ui/shell -run TestGenerateUIPreview -v
```

## UI-1: layout

- Top: compact menu-style row and colored icon command toolbar.
- Main: a connection explorer with search, resizable central workspace, and
  optional right information panel, all backed by `ui.SplitPercent`.
- Center: permanent Objects tab, context commands and object table; SQL editor
  and data preview open in additional tabs.
- Bottom: a fixed status bar, with explicit "UI Preview" label.
- Theme: compact dark neutrals, blue selection, self-authored SVG icons.
- Resizing defaults: sidebar 22% of window; center 75% of remaining width;
  user can drag both splitters.

The native operating system retains ownership of the physical titlebar,
window buttons and normal focus/IME behavior.

## UI-2: implemented mock interactions

| Interaction | Outcome |
|---|---|
| Click a connection in the left tree | Selects a mock connection; renders object rows; updates inspector/status |
| Expand a connection node | Displays mock schema/table children |
| Type in connection search | Filters the connection roots (including Chinese text) |
| Toolbar: 新建查询 | Opens a new independently editable SQL tab |
| Toolbar: 表/视图/函数 | Switches Object tab and filters mock object types |
| Open selected table / double-click table row | Opens a virtualized synthetic Data Preview tab |
| SQL tab: 运行模拟查询 | Increments a demo counter and updates status; never runs SQL |
| Close current tab | Closes non-permanent tabs; Objects tab cannot close |
| Toolbar: 信息 / info panel close | Hides or restores the inspector |
| Resize splitters | Changes sidebar/inspector widths |
| Other toolbar/menu placeholders | Displays explicit not-yet-implemented status |

Data Preview contains **100,000 virtual rows and 50 virtual columns**, whose
cell text is constructed on demand. This is not a database query or
server-side pagination benchmark.

## Code ownership

- `internal/ui/theme/`: compact dark palette and original SVG symbols.
- `internal/ui/shell/model.go`: workbench state, tabs, mock objects and
  synthetic result cell generator.
- `internal/ui/shell/chrome.go`: top chrome, command toolbar and statusbar.
- `internal/ui/shell/explorer.go`: mock connection explorer and search.
- `internal/ui/shell/workspace.go`: object table, SQL editor, virtual result.
- `internal/ui/shell/inspector.go`: contextual right panel.
- `internal/ui/shell/shell_test.go`: headless interaction regression tests.
- `internal/ui/shell/preview_test.go`: opt-in screenshot generator.

## Limitations / next steps

- Connection profiles, database credentials, SQL execution, metadata requests,
  and result paging are **not yet implemented**.
- Object toolbar actions such as import/export and structure editing are
  intentionally status-only placeholders.
- Menu-style row is an in-window mock command row, not a full native OS menu.
- Layout sizes are retained only in memory for this run; persistence is M1.
- Physical OS GUI testing is still required on Windows, Linux and macOS:
  check titlebar, IME, DPI scaling, pane drag, keyboard navigation, tooltip
  overlay and horizontal grid scrolling.
